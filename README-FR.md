## Paiement et prix
Les deux boutons ouvrent https://lecoffredutapissier.impultienda.ar/checkout.
Le script https://lecoffredutapissier.impultienda.ar/embed/upsells.js renseigne data-main-price et data-main-original-price selon le catalogue et la localisation de l’acheteur. Aucun prix n’est codé en dur. Le catalogue a répondu avec US$21.99 et un prix antérieur US$49.99 lors du contrôle.
Aucun markup data-upsell-* dans la page : les offres complémentaires restent dans le checkout. Le script conserve les paramètres d’attribution pour le parcours d’achat. Le message d’offre est « Paiement unique · Sans abonnement ».
