# Le Coffre du Tapissier

Page de vente française, avec styles, scripts, images et polices locales.

- Page : `inicio/index.html`
- Aperçu local : `python3 -m http.server 8000`, puis ouvrir `http://localhost:8000/inicio/`.
- Contrôles : `python3 validate.py` et `node --check inicio/app.js`.
- Paiement : les deux boutons conservent le checkout français Impultienda et les tarifs dynamiques.
- Attribution : les intégrations UTMify de la page source sont conservées.

Cette copie ne déclenche aucun déploiement. Les métadonnées de prévisualisation et la configuration de suivi sont conservées sans changement ; revoir les exigences de consentement et le parcours d’achat avant un lancement public.
